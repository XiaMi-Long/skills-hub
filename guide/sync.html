同步 ​

把某个 agent 下的技能副本复制到其他 agent。

操作 ​

详情页点「同步到…」:

  1. 选择目标:8 个 agent 复选卡片,默认勾选「还没有副本」的;已有副本的带橙色「已存在」徽标,默认不勾选。支持全选/清空
  2. 冲突决策:若勾选了「已存在」的目标,进入冲突页——逐目标选择 覆盖 / 跳过,或「应用到全部」
  3. 执行:逐目标收集结果,成功失败互不中断,结果页按 agent 逐条 ✓/✗ 展示

语义 ​

  • 同步 = 递归复制整个技能文件夹(SKILL.md + 辅助文件)
  • 采用 staging → rename 原子替换:先写临时目录,最后一步替换,中断不会毁坏原目录
  • 符号链接跳过并记录,不跟随

典型场景 ​

  • 在 Claude Code 里打磨好一个技能 → 同步到 Codex、Cursor、Universal
  • 列表行出现橙色漂移圆点(副本内容不一致)→ 选一个最新副本作为源同步覆盖其余
