技能管理 ​

查看技能 ​

列表支持按名字、描述模糊搜索(Ctrl+F 聚焦搜索框)。点击技能行进入详情:

  • 顶部徽标展示该技能存在于哪些 agent,点击徽标切换查看不同副本
  • 视图模式渲染 SKILL.md(支持 GFM 表格、代码高亮),排版可在设置里切换「极简 / 文档 / 暖纸 / 紧凑」四种主题
  • 详情头展示绝对路径、辅助文件数等元信息,可一键在资源管理器中定位

编辑技能 ​

详情页切换到编辑 tab(CodeMirror 原文编辑):

  • Ctrl+S 保存;取消丢弃修改
  • 保存前会校验磁盘 mtime:若文件被外部修改过,会弹出「磁盘已变化,仍覆盖?」二次确认
  • 翻译视图下禁止编辑(避免译文被误改),切回原文即可

新建技能 ​

右上角「新建技能」→「手动创建」:

  • 名字校验 ^[a-z0-9]+(-[a-z0-9]+)*$(小写字母、数字、连字符)
  • 描述 + 正文 Markdown(带模板占位)
  • 目标 agent 支持全选或单选,与「同步到…」弹窗同款样式;已存在同名技能的 agent 会标「已存在」,勾选「覆盖已有副本」后才可提交

删除技能 ​

详情页「删除」:

  • 可选「仅此副本」或「所有副本(N)」
  • 红色确认按钮,防误删

漂移提示 ​

同一技能在不同 agent 的副本内容不一致时,列表行右侧显示橙色圆点,详情标题旁显示「副本内容不一致」——方便你决定要不要同步。
