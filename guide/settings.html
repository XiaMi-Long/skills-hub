外观与设置 ​

主题 ​

暗色 / 亮色 / 跟随系统。主题按钮带功能性动画:暗色月牙星星闪烁、亮色太阳光芒旋转、跟随系统屏幕昼夜流转;选中与悬停以水波纹晕染。

色调 ​

蓝 / 橙 / 绿 / 紫 / 粉,作用于主按钮、选中态、进度条与交互光晕。色调按钮同样为光晕浅渐变 + 水纹晕染交互,无大色块。

全局质感背景 ​

开启后:

  • 窗口启用 Windows 亚克力透明(可透到桌面)
  • 叠加渐变背景、颗粒噪点、磨砂玻璃与半透明面板

关闭则为实心纯色风格。设置卡片内嵌迷你窗口,实时演示开关效果。需要 Windows 10/11 且系统「透明度效果」开启。

阅读样式 ​

技能预览的 Markdown 排版主题:极简(默认)/ 文档(accent 分隔线)/ 暖纸(衬线阅读风)/ 紧凑(高密度)。四个样式以紧凑胶囊按钮呈现,各带文字线条图形与波动动画,与主题、色调完全同体系。

Agent 路径 ​

默认按各 agent 约定目录扫描;可逐个覆盖为自定义路径,或重置默认。

DeepSeek ​

API Key、模型、base_url、目标语言、默认视图与连接测试。Key 仅明文存本机。
