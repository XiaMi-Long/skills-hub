# 翻译阅读

借助 DeepSeek 把英文技能翻译成中文阅读,带内容寻址缓存。

## 前置

设置 → 翻译 中配置:

- **API Key**(明文仅存本机 app 数据目录,页面有警示)
- 模型(默认 `deepseek-chat`)与 base_url(默认 `https://api.deepseek.com/v1`)
- 目标语言(中/英)与打开技能时的默认视图(原文/译文)
- 「连接测试」按钮可验证配置

## 单技能翻译

详情页点「翻译」:

- 流式输出译文,边译边渲染
- 命中缓存直接展示(不重复花钱)
- 翻译视图只读,编辑需切回原文
- 译文完整后可「用译文替换原文」(带二次确认与磁盘变更检测),替换后译文登记为新内容的缓存

## 缓存机制

- **内容寻址**:key = 内容哈希 + 目标语言 + 模型 + 提示词版本;同一内容的多个 agent 副本共享一份翻译
- **三态**:hit(有缓存)/ stale(原文已变,展示旧译文 + 「原文已更新」横幅)/ none(未翻译)
- 打开技能时按默认视图自动读缓存,绝不静默重译

## 一键翻译全部

设置 → 翻译:扫描全部实例按内容去重后顺序翻译,进度条实时上报,可随时取消;相同内容的副本共享结果。
